# 审阅 UI 更新：1.4.220-forflow.2

用户要求统一审阅的 UI、文案和可读性，并明确优先「发起审阅与选择材料」。本版先让项目、要求和材料形成清晰的顺序，再统一项目／对话审阅页头与 Jev 操作。

## 界面与交互

- 项目入口使用有名称的三步导航，Jev 使用同样的四步导航。按钮明确显示「下一步：检查要求」「下一步：选择材料」「开始审阅」「下一步：预览材料」「发送给 Jev」。
- 文件列表提前显示，勾选行突出已选状态。已选材料显示可读文件名、用途及移除操作；数量同时显示在提交按钮旁。
- 长路径、选材时的检查要求及来源信息按需展开。操作教学仍使用原生气泡，由「操作说明」展开，默认收起。
- 项目和对话审阅共用紧凑页头，保留版本选择、评论、检查状态及常用操作。Jev 结果使用「主要发现／建议下一步／查看材料／记录问题」。
- Jev 切换步骤或返回页签后，当前操作区滚动到可见位置。

继续复用既有材料读取、选择状态、预览失效和审阅版本机制。返回保留选择；项目变更清理对应草稿；发送仍由预览页的明确操作触发。文件数量、主机可读性和来源变化检查沿用原规则。
