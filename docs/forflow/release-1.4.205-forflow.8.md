# Computer Use 实测后的介绍与状态修复

版本 `1.4.205-forflow.8`，macOS arm64 本机测试版。构建、安装、测试结果与源代码指纹以随包 `release.json` 为准。

本轮按用户要求，由 GPT-6 Astra、medium 子代理使用 Codex Computer Use 实际点击安装版。检查产品介绍连续 11 个页面、完成关闭和重开、八项入门详情、关于窗口、Finder 应用列表及国内接入导航。实际点击发现此前静态中文检查遗漏的动态英文、语义误译和 CLI 状态错误。

## 修复

- 修正用量说明、并行测试进程、编辑器输入提示、行号、测试覆盖评论及“供其他智能体读取”等文案。`stderr`、网页路由与示例命令恢复为正确技术文本。
- 编辑器动画的“发布检查清单”和“复制”按当前语言生成；推理强度选项复用现有本地化标签，保持实际配置值不变。
- 系统应用菜单的关于、服务、隐藏、退出及窗口操作使用中文，保留原生菜单角色和快捷键。上游开源版权归属保留。
- CLI 注册状态遭遇 EACCES／EPERM 或其他读取失败时，持久展示中文错误并可刷新重试；清除失效的旧状态，禁用依赖未知状态的安装／删除操作。没有修改链接权限、覆盖未知命令或自动提权。
- 修复 macOS 管理员安装事务沿用 `umask 077`，将新建链接生成为 root 私有 `0700` 的根因；新发布链接使用可读权限，事务暂存目录继续保持私有。已存在但无法读取的命令仍拒绝覆盖。
- 通知详情明确清单完成只按应用内开关计算，系统权限与实际送达另行检查；浏览器说明改为页面结构与样式，避免承诺可以获取准确源码。

八项清单与原进度逻辑完整保留；现有项目、智能体参数和权限设置没有因界面测试而改写。

## 验证

加入 CLI 读取失败、拒绝修改未知链接、恢复刷新和旧状态失效回归；介绍测试连续点击“继续”，核对栏目与子页顺序，完成关闭后重开，并开启真实动画检查动态中文。安装包检查覆盖中文原生菜单与圆角图标输入。其余身份服务、八项入门、国内接入导航、权限及本机上传确认沿用完整回归。

可见 Computer Use 与隐藏 Electron 测试分别留证。Finder 与关于窗口中的原字标、绿线及单层圆角底板已实测；Dock 专用自动化访问超时，不能因此声称该可见位置已通过。Forflow 自身电脑控制仍需独立授权；本轮可见点击使用 Codex Computer Use，不等同于 Forflow 自带电脑控制已可用。

本机原有 `/usr/local/bin/forflow` 为 root 所有且权限为 `0700`，读取失败已复现；本版不会自动更改无法确认目标的链接，管理员需核对后修复，不能将受控错误展示记作 CLI 已注册可用。

真实国内 API、第三方 CLI 登录、国内历史解析、完整 CLI 汉化和客户部署没有在本版新增完成。
