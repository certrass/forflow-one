# 1.4.220-forflow.9 · 连接引导

## 界面

- 智能伙伴按用途介绍；连接指引按需展开，命令与应用参数收在详情里。
- 豆包工作伙伴可以按名称选择，随后仍从标准任务入口继续对话。设置与 CLI 共用伙伴配置。
- 飞书任务移到集成页首位；首次设置分三步，已有授权直接连接，连接成功后进入任务页。
- 连接错误给出下一步动作，远程与 WSL 范围不使用本机伙伴身份。

[设计说明和 QoderWake 核对](connection-guidance.md)记录了参考流程与当前实现。QoderWake 的扫码、聊天配对、Waker 指派是三层接口；本版没有新增 IM 自动回复。

## 验证

macOS arm64 完成 343 文件／3,574 项国内回归、11 项身份测试、45 项连接相关测试（与国内回归存在重叠）、完整类型检查与构建、中文目录检查和改动行规范检查。产品运行验证使用独立 HOME、模拟官方 CLI、隐藏 Electron 窗口，不向真实飞书聊天发送消息。

首次界面验证发现两个测试前提不符：从设置返回后的会话需要点击「对话」，切换主题重载后设置回到「通用」。按实际操作复验；任务页仍需明确点击「读取任务」，未改变已有读取约定。同时修正了复用连接卡时，已连接状态不应再次显示「连接飞书」的按钮。

成品、运行截图、指纹与安装回执位于本机 `Library/Caches/Forflow One/builds/1.4.220-forflow.9/`。截图均为模拟账号和任务，QoderWake 授权二维码留在本机。
