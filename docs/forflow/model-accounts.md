# 国内模型 API 账户

适用于 Forflow One `1.4.205-forflow.10` 起的桌面客户端。本轮按用户确认的“先接官方 API Key／充值余额”开发。

## 配置与测试

1. 打开「设置 → AI 提供商账户」，将执行主机切到本机。
2. 在 Kimi、智谱 GLM 或 DeepSeek 卡片填写开放平台的模型名称和 API Key。模型名以你的平台账户实际可用项为准，输入框中的名称仅为示例。
3. 点击「保存配置」。密钥加密保存在本机；输入框随后清空，页面不回显已保存的密钥。
4. 点击「测试连接」才会发送固定的简短测试文本，可能使用少量 API 额度。未点击测试前，保存和打开页面不会调用模型。
5. 修改模型时，API Key 留空可保留原密钥；修改后须先保存再测试。「移除配置」删除该提供商在 Forflow 中保存的凭据，不会撤销平台上的 API Key。

| 提供商 | 固定 API 地址 | 官方说明 |
| --- | --- | --- |
| Kimi／月之暗面 | `https://api.moonshot.cn/v1` | [获取 API Key](https://platform.kimi.com/docs/get-api-key) |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | [OpenAI 兼容接口](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction) |
| DeepSeek | `https://api.deepseek.com` | [API 文档](https://api-docs.deepseek.com/) |

接口地址根据 2026-09-20 核对的官方文档固定，不接受任意地址替换。内网网关配置作为后续功能。

## 状态与范围

- 「已保存 API 配置」表示本机配置已保存；连接测试的结果单独显示。认证、限流／额度、网络或服务异常不会显示成连接成功。
- 系统密钥库不可用时不会退回明文。已有配置无法解密时保留原文件；先处理密钥库问题，不要反复覆盖。
- 测试仅请求模型接口，最多等待 15 秒，不自动重试。响应可能仅含推理文本或因测试长度限制被截断；成功表示接口接受了请求并返回内容。
- 当前支持每家一个官方 API Key，不提供网页会员、Kimi Code 或智谱 Coding Plan 登录，也不查询或展示充值余额。
- 本机 API 配置暂不自动注入智能体 CLI。CLI 仍使用自身的登录和模型配置；Forflow 企业成员账号也独立管理。
- SSH、WSL 和网页客户端不会借此入口读写本机密钥。切回本机管理账户；远程执行环境的密钥仍按该主机单独配置。

测试代码使用合成密钥和模拟响应。真实账户可用性需在用户填写自己的密钥后，由用户点击测试确认；开发验证不读取用户此前预留的模型环境文件。
