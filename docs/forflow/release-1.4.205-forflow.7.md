# 产品介绍与 macOS 圆角图标修复

版本 `1.4.205-forflow.7`，macOS arm64 本机测试版。实际构建、安装与验证结果以交付目录 `release.json` 为准。

用户再次指出“图标有问题，然后介绍也有问题”。此次直接检查安装版的系统「帮助 → 探索 Forflow One」，复现了标题中文、正文和导航英文的问题：`Workspaces`、`Agents`、`Workbench`、`Code Review`、`Continue` 及 Orca 正文仍存在。此前八项入门与设置页面的验证没有覆盖此独立介绍页。

## 修改

- 5 个介绍栏目和 9 个子页从共享配置进入翻译层；导航、标题、说明、继续按钮及页脚随语言切换更新，保持原 ID、顺序、完成进度及操作。
- 参照官网操作文档和本版手册，说明工作区、任务来源、智能体状态、终端、编辑器、浏览器和审阅。修正“所有账户用量”“完全隔离”等过宽表述，标明国内历史与真实执行仍需相应适配。
- 中文化工作区示例名称和状态动画中的说明；用户项目名称、第三方产品名称、命令、文件路径保持原样。
- 私有版首页移除上游 GitHub 推广入口，也不再查询上游仓库点赞状态。
- 在应用内「帮助」菜单增加「产品介绍」入口；系统菜单原入口保留。
- 首页放大显示现有 ForFlow 字标，移除小字标外套深色方框；首次引导按横向比例展示，清单导航采用可辨认的功能图标。
- 根据用户补充“不是圆角”，将原本直接覆盖 Dock 的方形图改为 macOS 圆角导出资产；应用 ICNS 全尺寸、运行时 Dock／窗口图标和外观预览统一使用圆角版本。
- 首页增加简明产品介绍，「关于」窗口增加产品说明并翻译图形加速状态。

原始 ForFlow 字标和绿色线条保留，新增圆角应用图标从 macOS 对现有 Forflow 应用的原生图标解析结果导出，没有重绘品牌。`forflow-app-icon.png` 与首页使用的 `forflow-mark.png` 分工明确；ICNS 可由 `config/scripts/export-forflow-icon.mjs` 重复导出。Computer Use 本轮连接超时，实时 Dock／关于窗口未通过可见界面复验；已核对系统图标解析、所有尺寸透明圆角及 Electron 实际图标调用。

## 验证范围

新增介绍页回归从真实帮助菜单进入，逐一打开 5 栏目／9 子页，检查中文说明并保留截图；原八项入门、项目操作、国内接入导航、自有账号、权限与本机上传场景继续回归。

真实模型调用、第三方 CLI 登录与国内历史解析没有在此版新增完成。完整 CLI 帮助仍有英文及旧名称，操作手册继续保留该已知问题；上游技术兼容标识和许可证没有伪装改写。
