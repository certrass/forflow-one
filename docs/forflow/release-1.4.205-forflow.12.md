# Forflow One 1.4.205-forflow.12 本机测试版

2026-09-20，macOS arm64，国内私有默认配置。当前状态：安装包已通过验证，等待正在运行的 `.11` 正常退出后安装。

用户纠正：“cli是不是名字还是不对，cli部分你也得修改一下吧”。`.11` 的入口已叫 `forflow`，但 CLI 独立编译，帮助仍使用 `orca`。本版为 CLI 增加独立产品身份，帮助、命令示例、恢复建议和随包指南改用 Forflow；根帮助和 234 条命令简介改为中文。

技能可用 `forflow-cli` 等新主题名读取，旧别名和目录继续兼容。`skills install/update` 复用现有离线安装事务，支持预览、项目范围、JSON 和已支持的智能体入口。保留已编辑文件及外部符号链接，SSH 转发时拒绝在错误主机安装。诊断写入 stderr，保证 JSON 输出可直接解析。桌面包不再携带 npm 开发命令元数据；系统入口仍由 `Resources/bin/forflow` 注册。

新环境变量 `FORFLOW_USER_DATA_PATH`、`FORFLOW_ENVIRONMENT`、`FORFLOW_PAIRING_CODE`、`FORFLOW_APP_EXECUTABLE` 等映射到兼容内核。用户输入、第三方输出、JSON 字段、远程协议、权限语义及 MIT 来源声明保持真实。
