## 本版体验

- 设置 → 实验性功能新增「接续预检 · Beta」，默认关闭，可搜索“接续”定位。
- 启用后在 Codex 对话中按需预览整条用户原文及最多三条近期 Agent 回复，展示来源、遗漏和 24,000 字节预算。
- 明确区分用户原文与“未核实”的 Agent 陈述。历史未完整加载、来源无法区分、关键用户文本缺失或超出预算时禁止复制；会话变化要求刷新，切换窗格清除旧预览。
- 显式复制 JSON 交接材料与 SHA-256 来源回执。不调用模型，不自动发送、改变任务状态或写入长期记忆；不改变原有八项入门。
- 两种会话视图复用现有内容布局，保留转录与结构化会话各自的执行接口和宿主边界。

操作见 [接续预检使用说明](context-handoff-beta.md)，后续自动接续、候选提取、审计和资产阶段见 [系统规划](governance-memory-beta-plan.md)。本包包含 `.16` 飞书任务和 `.17` 新手指引，无需依次安装。
