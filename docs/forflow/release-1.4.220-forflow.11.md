# 豆包启动与并行提示 · 1.4.220-forflow.11

用户反馈豆包终端打开慢、不能并行调用。现场只读测量中，旧版 CLI 输入就绪约 1.266 秒，飞书历史读取约 1.073 秒，账号检查约 0.115 秒；没有复现持续网络卡顿。代码确认打开流程等待整轮历史同步，同一伙伴再次打开会被会话锁拒绝，但对话页只显示加载提示。

## 改动

- 已绑定伙伴先检查账号并取得写入锁；CLI 安装输入处理后发布会话，历史在后台同步。可先写草稿，期间提交的消息复用现有队列。
- 连接未就绪时提供「查看连接情况」，打开该任务终端；重复打开说明原任务仍占用同一飞书聊天。
- 智能体选择和豆包的并行指引说明：同一伙伴一次在一个任务中使用，可同时运行 Codex、Claude 或 WorkBuddy。没有将固定单聊伪装成独立多会话。
- 历史请求晚于关闭返回时，不再写入已经释放的会话；账号检查同时复核磁盘绑定，避免另一进程切换伙伴时继续使用旧绑定。

新版真实只读 CLI 测量：首条反馈 0.129 秒，输入就绪 0.476 秒，历史同步完成 1.303 秒。这是当前机器的一次对照，区别在输入不再等待历史。没有向真实飞书伙伴发送测试任务。
