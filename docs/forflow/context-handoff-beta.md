# 复制对话内容

适用版本：1.4.220-forflow.1，Codex 对话视图。原入口「接续预检 · Beta」改名为「复制对话内容」。

## 使用方法

1. 在「设置 → 实验性」打开「复制对话内容」。
2. 打开 Codex 对话，点击输入框上方的「复制对话内容」。
3. 查看摘录，点击「复制到剪贴板」。
4. 粘贴到新对话，接着提出要处理的任务。

主视图按原顺序显示「你」和「Codex」的文字。默认复制可直接阅读的文本，保留原文与换行。对话更新后，点击「更新摘录」取得最新摘录。

## 摘录与来源

摘录包含当前会话中已加载的用户原文，以及最多 3 条近期 Codex 回复。附件和工具结果可在目标对话中另行添加。

展开「来源详情」可查看会话标识、24,000 UTF-8 字节容量和遗漏数量。「复制来源回执」另外导出带 SHA-256 指纹的 JSON，包含会话、窗格、工作区、消息标识与时间，便于核对原记录。

正在执行、记录加载未完成或有消息等待发送处理时，页面提示对应操作。源记录截断或文字超出复制容量时，可恢复记录，或在原对话中选取所需片段。

实现复用原有记录筛选和版本检查；本次调整聚焦入口、文案、内容布局与复制格式。历史实现与验证见 [`.19` 记录](release-1.4.205-forflow.19.md)，当前升级与测试见 [v1.4.220 整合记录](upstream-v1.4.220-integration.md)。
