# Forflow One 1.4.205-forflow.10

## 新增功能

「设置 → AI 提供商账户」增加 Kimi、智谱 GLM 和 DeepSeek 官方 API Key 配置。支持本机加密保存、保留密钥修改模型、移除配置和显式连接测试；页面支持中文及提供商别名搜索。模型名称可编辑，接口地址固定为各家官方地址。

密钥不会回传给界面，不写入普通设置；系统密钥库不可用时拒绝保存，不降级为明文。测试只发送固定短文本，有超时、响应大小限制和中文失败提示。保存、移除会取消进行中的测试。SSH、WSL 或网页视图不读取本机凭据。

使用开放平台充值额度，不是网页会员或 Coding Plan；暂不显示余额，也不自动修改 CLI 的登录与模型设置。详见 [配置手册](model-accounts.md)。

同时包含前次已完成的本地智能体自定义 CLI 路径配置、保存后重新检测及工作区启动衔接，见 [国内 CLI](domestic-cli.md)。
