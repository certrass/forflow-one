# 1.4.220-forflow.10 · 并行与产出对比引导

会话工具栏新增「并行与对比」，按“分别发起任务 → 收齐产出 → 对比后选择”介绍完整路径，直接提供「同题再做一版」「准备对比草稿」和当前文件入口。原有不同任务的创建方式收在展开项。

两个模板均复用当前项目与任务创建流程。弹窗标题与说明随场景变化；新建任务的空白输入也提供这两个模板，已有草稿保持原样。创建后仍在原生对话中添加产出文件或粘贴内容，再发送给所选智能体。当前并非自动搜集、分组或评分多个任务的结果。
