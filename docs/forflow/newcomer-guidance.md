# 新手指引：从一个小任务开始

适用 `.17` 测试版。先选一个本机测试项目，完成“写目标 → 提供资料 → 发送 → 检查结果”，再使用并行或外部任务来源。

## 在哪里找到引导

| 位置 | 提供的帮助 |
| --- | --- |
| 创建任务／并行任务窗口 | 「不知道怎么写？从一个示例开始」：理解项目、实现小改动、检查已有改动 |
| 会话顶部「操作指引」 | 对话、文件引用、分屏与并行、结果审阅、浏览器设计反馈五个主题 |
| 操作指引底部「指给我看：分屏与并行」 | 重新显示指向具体控件的浮层；可返回或按 Esc 关闭 |
| 任务页「从任务到结果：使用指引」 | 创建任务、连接来源，以及项目／工作区／分屏的区别 |
| 设置 → 入门清单 | 原有八项清单，以及下方的六步首个任务说明 |

查看或关闭说明不会创建任务、标记业务完成或发送消息。浮层中的「拆分终端」是实际操作按钮，点击会增加窗格；仅阅读时可直接关闭。

## 第一个任务

1. 添加 Git 项目或普通文件夹，核对执行位置。第一次可先使用本机小项目。
2. 安装并登录 Codex，在「设置 → 智能体」检测。Forflow 账号、模型 API 账户和 Codex 登录分别配置。
3. 创建任务，展开示例并选择「先理解项目」。示例先要求阅读和解释，不修改文件。已有说明时示例按钮禁用，避免覆盖手写内容或飞书来源资料。
4. 根据项目修改说明，选择智能体，点击「创建并准备对话」。这一步准备草稿；核对后点击发送才执行。
5. 检查答复与引用文件。需要修改时先说明预期结果；最终核对实际文件及测试结果。

示例中的方括号是待填写内容，需在发送前替换。示例是任务说明，不是平台强制权限策略；实际执行仍依赖所选智能体的授权与配置。

## 工作时遇到疑问

- **对话与终端**：支持的桥接会话可以切换展示，继续使用同一会话。结构化会话没有同一个底层终端；不可切换时读取按钮旁原因。
- **文件引用**：把文件从文件面板拖到对话输入区；引用标签代表路径，不是自动上传副本。远程任务需要目标主机能读取文件，发送后的资料处理取决于智能体和模型配置。
- **分屏与并行**：分屏共用当前工作区文件。独立修改 Git 项目时创建另一个工作树与分支；普通文件夹不会自动隔离改动。
- **结果审阅**：Git 项目使用「查看更改」，普通文件夹检查实际输出文件。差异面板包含工作区所有改动；打开面板不会提交或发布。
- **网页与设计反馈**：先启动项目网页服务，再打开浏览器预览地址。选取元素或标注意见后发送给目标智能体，检查其回应。
- **飞书任务**：按 [飞书连接指引](feishu-tasks.md) 授权，读取清单和任务，先预览详情再导入；来源系统状态不会自动回写。

引导可用键盘打开，按 Esc 关闭，并可从原入口重看。浮层只显示当前可用目标；完整入门清单及已有完成状态保持原规则，不因阅读教程自动计为完成。
