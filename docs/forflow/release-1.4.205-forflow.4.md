# Forflow One 入门中文与启动图标修复

版本 `1.4.205-forflow.4`，macOS arm64。本版针对用户实测的入门英文残留、启动后仍出现 Orca 图标，安装和最终验证以交付目录 `release.json` 为准。

## 修复与原因

- 启动图标原先仍读取上游 `classic / blue / watercolor` 素材；本机保存的设置为 `blue`。现在三种旧设置都使用 Forflow 原品牌图像，清除旧的自定义 Dock 图标元数据，让 Finder 使用安装包中的 Forflow 图标。外观页展示 Forflow 图标，菜单栏也改用已有的 Forflow 透明字标与独立提示文字。
- 本机保留的 `.1` 应用可复现用户贴出的八项英文标题；`.3` 的中文包已包含对应翻译。本次在正式安装包中分别验证“帮助 → 里程碑 → 入门”弹窗和“设置 → 入门清单”，逐项断言八个标题和八段说明的具体中文，而非只判断页面是否出现中文。不能仅凭旧版复现断言用户当时启动了哪个文件。
- 项目首页“创建工作区／工作树”“上一个工作区”“下一个工作区”接入翻译目录，修复直接写死的英文。入门总说明改为自然中文，计算机控制中的“手机光标”纠正为“移动光标”。
- 八项清单、完成条件、已保存进度与操作入口继续保留。品牌映射保留底层兼容标识和开源许可来源。

## 验证范围

- 740 项单元／集成回归，67 个测试文件；11 项身份服务接口测试。
- 正式安装包的 8 个 smoke／端到端场景覆盖：首次启动、首页与图标、入门弹窗及设置页、重启后的中文、清单进度与离线技能、账号及会话、权限和实际上传、本地项目／工作树／中文终端／文件编辑／差异及并行任务浮层。
- 图标测试从已保存的 `blue` 配置启动，通过真实设置 IPC 分别切换三种旧图标值，核对传入 Electron Dock／窗口图标接口的图像与 Forflow 素材一致。隐藏测试没有声称目视确认系统 Launchpad／Dock 缓存。
- 生产类型检查、安装包测试类型检查、改动代码质量、中文目录及运行时目录检查；构建与签名校验。

测试使用隐藏窗口和隔离 HOME／用户数据。旧 `.1` 的复现及测试脚本调试失败保留在本机证据目录；最终通过结果单独保存，未把失败尝试改写为通过。仍是本机 ad-hoc 签名测试版，未公证；国内模型真实调用继续等待用户配置凭据。

## 使用与回退

固定使用 `/Applications/Forflow One.app`。在“设置 → 通用 → 版本与升级”核对 `1.4.205-forflow.4`，避免打开交付目录里保留的旧 `.1` 应用。

安装前保留 `.3` 应用供回退；应用程序替换不修改用户项目、账号服务数据或原 Orca 应用。具体回退路径、安装包校验和及安装后的检查结果见 `release.json`。
