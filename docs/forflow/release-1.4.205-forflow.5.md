# Forflow One 桌面汉化与品牌资源修复

版本 `1.4.205-forflow.5`，macOS arm64 本机测试版。最终安装路径、源码指纹、测试数量与制品校验以交付目录 `release.json` 为准。

本轮按用户“先做全量汉化，然后图标还没改”的反馈，将检查扩到整个桌面和设置页面。语言目录已有中文不等于实际界面全部调用了翻译；此前测试没有覆盖动态目录、内置编辑器和内嵌图形。

## 实现

- 补齐快捷键动作与分组、搜索目录、Git 操作及变量说明、斜杠命令说明、任务与智能体状态、下载和权限提示、文件与差异标题、复制结果、自动化时间、语音模型说明、模拟器操作及状态、无障碍标签和自定义组件参数中的漏译。动作 ID、快捷键绑定、变量名和用户内容保持原值。
- 引导中的动画示例、浏览器／模拟器示例提示词、评注、提交和编排演示接入运行时翻译；完整保留原八项入门清单、完成条件、进度及操作入口。
- Forflow 构建在 Monaco 初始化前加载同版本自带的中文 NLS，覆盖编辑器内置查找、替换及相关提示；终端与通知组件的界面标签接入中文。
- 应用主进程和渲染进程的旧图标导入统一映射到既有 Forflow 素材，安装包排除旧应用图标资源。用量卡片和移动端介绍页内嵌的旧矢量图改为统一品牌图片；修正设置清单图标沿用旧反色样式的问题。继续使用原有 `resources/forflow/brand-source.json` 所记载的品牌素材。
- 模拟器命令示例在私有版本中使用已提供的 `forflow` 命令，终端预览使用 Forflow 示例路径。真实终端输出、代码、文件名、第三方产品名与外部服务返回内容不做文本改写。

## 验证

回归集扩到受影响模块的相邻测试，覆盖既有权限、上传、身份、清单与工作区行为；新增中文快捷键、语言切换、固定命令说明、状态和构建资源测试。构建步骤执行生产类型检查、身份服务测试、单元回归和签名。

正式制品与安装后的应用均使用隔离 HOME、隐藏 Electron 窗口验证：首次启动、八项清单与重启、29 个设置页面的文本／属性／截图、旧图标偏好迁移、账号会话、权限和实际上传、本地项目／工作树／中文终端／文件编辑／差异／编辑器查找及引导浮层。测试不使用真实模型密钥。

图标证据包含安装包 ICNS 与品牌原图比对、旧资源排除检查、页面截图，以及实际 Dock／窗口接口接收的图像。Computer Use 本轮因锁屏和工具超时未能完成系统应用列表的目视核验；这部分不标为已通过。最终通过记录与首次定位过程中失败的记录分开保留。

## 使用

从 `/Applications/Forflow One.app` 启动，在“设置 → 通用 → 版本与升级”核对 `1.4.205-forflow.5`。安装前保留 `.4` 回退副本，不变更原 Orca 应用或用户项目。

本版为本机 ad-hoc 签名测试包，未公证、未公开发布；真实国内 API 验证仍等待用户配置凭据。
