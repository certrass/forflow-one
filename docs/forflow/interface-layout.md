# 字体与排版统一

本轮从安装版 `.12` 的实际画面复查任务页、会话工具栏和材料审阅，再调整现有组件。基线截图于 2026-10-07 重新运行获取，位于 `~/Library/Caches/Forflow One/design/typography-layout/before/`。

## 判断与改动

任务入口原先分散在标题右侧和第二行，说明字号也不同。现在三项动作同排、说明同起点；任务来源与筛选放在分隔线下，关闭入口在标题行末。保留现有任务、比较草稿和审阅行为。

会话工具栏原先把关键动作压在 24px 小按钮里，并重复展示标签页已有的智能体名称。现在关键按钮统一 32px、文字 14px、图标 16px，聊天与终端归为一组，操作区与其分开；只在需要切换或启用说明时展示状态文字。

审阅原先重复展示“审阅结果”“发起项目审阅”和当前步骤，外层卡片再套文件卡片。现在弹窗复用同一表单的嵌入模式，去掉中间标题和外框；项目名称放在当前步骤旁，步骤条减轻字重。宽度足够时文件列表与已选材料并排，容器窄于 40rem 时顺序堆叠。用户可以直接核对文件用途，操作按钮保留在滚动区域底部。刷新项目保留在选择项目这一步。

## 后续沿用的层级

| 角色 | 本轮采用 |
| --- | --- |
| 页面、弹窗标题 | 18px，600 字重 |
| 内容、主要操作、说明 | 14px；普通说明用常规字重 |
| 步骤、项目来源和补充提示 | 12px；只强调当前步骤 |
| 常用按钮 | 32px 高；表单提交沿用 36px |
| 表单分组、工具区 | 16px 分组间隔；相关文字之间 4–8px |

实际渲染测量发现启动时的字体设置会覆盖 CSS 中已有的中文回退顺序。已让 `buildAppFontFamily` 与该规范一致：用户自选字体优先，随后使用 Geist、PingFang SC、Microsoft YaHei、Noto Sans CJK SC 与系统字体；主窗口和独立窗口共用这一构造函数。路径才使用等宽字体。继续使用 `docs/STYLEGUIDE.md` 与已有控件的尺寸、颜色、边框和焦点状态。材料选择布局按容器宽度切换，避免在设置侧栏和弹窗中产生不同挤压效果。
