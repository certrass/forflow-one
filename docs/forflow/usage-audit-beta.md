# AI 用量：费用口径与审计覆盖 Beta

2026-09-20。用户要求在“审计与用量是运行事件的不同投影”的基础上，明确估算、已结算、套餐分摊、不可计量，并分别说明上下文、模型调用、工具调用、数据读取的覆盖程度。

本次增量位于「设置 → 统计和使用情况」，现有用量图表下方。切换概览、Claude、Codex、OpenCode 或 Grok 时随来源更新，不替换原图表、筛选或扫描流程。当前实现是用量快照的证据说明；统一运行事件审计链仍是后续工作。

## 四类费用

| 口径     | 本版数据来源与行为                                                                                    | 后续完整计量需要                                                                             |
| -------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 估算     | Claude/Codex 已读 Token 与内置价格表；OpenCode 本地日志申报金额。展示美元已知部分，缺价不混成完整总额 | 定价版本、模型映射、缓存和重试规则、记录与运行关联；估算不能代替账单                         |
| 已结算   | 显示“未接入账单”，金额不填零                                                                          | 供应商原始账单、币种、账期、账单行 ID、对账凭据及修订记录                                    |
| 套餐分摊 | 显示“未配置分摊”，不根据账户套餐或 Token 占比猜费用                                                   | 实付金额、有效账期、规则版本、项目归属、分摊分母、未分配部分；分摊合计不得超过对应可分摊金额 |
| 不可计量 | 显示已读记录的明确缺价数、逐条完整性未知数；无记录时为“尚无法判断”                                    | 缺失原因、影响范围、补采或对账结果；无日志和缺价均不等于免费                                 |

这四种口径不是四笔可以相加的支出。同一活动可能先估算、后对账，再按项目分摊；必须靠活动 ID／账单行 ID 关联版本，避免重复计费。不同币种分别汇总，换算需显式汇率及日期。本版仅使用既有美元估算，不增加余额查询、账单下载或外部传输。

新增可选 `costCoverage = { pricedRecords, unpricedRecords, unclassifiedRecords }` 字段。Claude 的记录单位是已扫描轮次，Codex 是计量事件；两者都不是完整请求次数。统计与原有金额使用同一范围和时间过滤，支持文件夹工作区。OpenCode 的历史每日金额可能已将缺价事件折叠进小计，因此金额非空的聚合仍归为逐条完整性未知，不倒推全覆盖。不重写历史缓存；旧服务缺少字段或计数不一致时按未知处理。

## 四项审计覆盖

| 维度     | 当前页面如实展示                                                           | 尚缺的证据                                                |
| -------- | -------------------------------------------------------------------------- | --------------------------------------------------------- |
| 上下文   | 接续预检可以生成按需来源回执，但未关联到本用量账本                         | 调用实际输入版本、来源授权、脱敏与裁剪、发送回执          |
| 模型调用 | 已读到记录时为“局部可见”，可看 Token、模型和会话；无记录为“暂无可核验记录” | 请求 ID、失败和重试、实际模型路由、全部调用分母、账单核对 |
| 工具调用 | 会话可能显示活动，本账本尚未接入                                           | 调用与执行主机、参数摘要、权限决定、结果、证据引用        |
| 数据读取 | 项目／路径归属只是统计信息，本账本尚未接入                                 | 文件版本、表／字段范围、主体、授权依据、实际读取结果      |

按来源显示实际快照的范围、时间窗口、扫描时间和状态；读取失败保留“上次快照”提示。关闭来源不把其旧数据作为当前证据，Grok 套餐额度不复用其他来源的 Token 或金额。未接入的 SSH／其他主机不计为覆盖，不能从本机空白推断远端没有活动。

没有全部活动分母时不展示覆盖百分比；没有可信事件／结果关联时不展示“完整覆盖”。后续若展示比例，必须同列：应采集数量、成功关联数量、明确缺口数量、未知数量、来源主机、时间窗口和计算规则。来源记录本身缺失的调用不能藏在已读记录的分母之外。

## 后续小步补全

1. 将 B0 上下文回执以事件 ID 与具体发送／调用关联；先核验单个 Codex 会话，不抓取全盘正文。
2. 为模型和工具事件增加执行主机、尝试 ID、结果和证据引用；重放去重，失败也记录。敏感正文按权限保存摘要或引用。
3. 从受控读取入口采集实际数据访问与授权证据，不把终端文本推断作为事实。
4. 单独接入只读账单，完成对账后再增加分摊规则。用户确认实际账期与分摊依据前不生成“已结算”或“套餐分摊”金额。

新增字段仅为原用量快照的可选扩展。远端旧版本可省略，新客户端展示未知；不改变远程终端、Agent 状态或已有授权策略。
