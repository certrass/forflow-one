## 本版改动

- 「设置 → 集成」新增飞书任务连接，复用官方 CLI 的个人授权，提供检测、连接、重新检查、断开及首次配置说明。
- 「任务 → 飞书」支持我的任务、任务清单、完成状态、按页读取、已加载结果搜索和详情预览。查看来源与获取时间后，可选择项目并准备对话。
- 新建工作区增加「这次要完成什么？」输入；飞书任务或手动说明进入可编辑草稿，经用户发送后执行。Git 工作树和普通文件夹沿用原有创建流程，优先验证 Codex GUI。
- 任务来源增加文字标签，补充从任务到结果的三步引导，以及飞书授权、读取与排错教程。完整八项入门、既有任务来源、模型账户及专业工作台能力保留。

参考与取舍见 [任务体验升级依据](task-experience-upgrade.md)，操作步骤见 [飞书任务与任务清单](feishu-tasks.md) 和 [操作手册](user-manual.md)。
