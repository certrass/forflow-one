# 读取 Codex 自动化

从侧边栏打开 **自动化 → Codex（本机，只读）**，查看这台电脑上的 Codex 定时任务与会话跟进。可按名称或项目路径搜索，展开“任务详情”查看提示词、项目、模型与原始计划；在 Codex 修改任务后，点击“刷新”更新列表。

读取默认目录为 `~/.codex/automations/*/automation.toml`。启动 Forflow One 时设置了绝对路径 `CODEX_HOME` 的，改读该目录下的 `automations`；界面始终显示实际读取目录。Codex 会话历史的自定义来源与托管 CLI 账户目录不会改变这个来源。

这里显示的是任务配置。“已启用”表示 Codex 配置为 ACTIVE，“已暂停”表示 PAUSED，不表示当前运行或最近执行成功。Forflow 不复制这些任务到自己的调度器，也不运行、暂停、修改或删除它们。运行结果及执行管理仍在 Codex 中查看。仅查看任务不会调用模型。

复杂计划保留原文；界面只对可以准确识别的简单计划作中文说明，不估算下次执行时间。时区及实际触发以 Codex 为准。该入口始终读取本机，不读取所选 SSH 或远程运行时的 Codex 目录；不把本机结果当作远程任务。

没有任务时先核对界面中的目录与 Codex 是否在同一台电脑。读取权限、配置格式、未知版本等问题会单独提示，有效任务继续显示。支持当前版本 1 及无版本号的旧配置；文件超过 256 KB、目录超过 1,000 项或累计读取超过 8 MB 时会报告部分读取。删除后留下的记忆目录不会被当作任务，链接文件不会被跟随。

此入口复用现有自动化页面和桌面 IPC，新增本机只读读取器。原有 Forflow、Hermes、OpenClaw 与远程自动化继续使用原来的管理流程。
