# 并行与产出对比

## 使用路径

1. 在会话上方点「并行与对比」。三步引导直接展开，不再藏在操作指引的第三项。
2. 点「同题再做一版」，填写共同目标、参考资料和验收标准，选择智能体。创建后在各自对话中发送任务。
3. 从侧栏逐个打开任务，保存产出与验证记录，并标明版本。引导中的「查看当前任务文件」打开当前工作区文件。
4. 产出齐备后点「准备对比草稿」，修改版本 A、版本 B 与验收要求。创建后，在对话中添加智能体可读取的文件，或直接粘贴产出内容，再发送。
5. 按需求覆盖、正确性、使用体验、剩余工作逐项比较，核对材料依据后选择采用或组合方案。

新建任务的空白输入区也提供「同题再做一版」「对比两份产出」两个模板。开始编辑后收起快捷模板，保留已写内容。所有模板均为草稿；引导本身不创建或启动任务。

Git 项目可以给每版建立独立工作区。分屏共用当前文件，普通文件夹中的任务要分别指定产出文件或目录。跨主机比较时，将材料放在对比智能体可读取的位置，或粘贴内容。

豆包工作伙伴当前接续飞书里的固定单聊，同一伙伴一次在一个任务中使用。它可以与 Codex、Claude、WorkBuddy 并行；两个豆包任务不会自动变成独立对话。选择豆包和从豆包会话打开本引导时，会显示这一说明。

## 本轮设计依据

2026-10-07 从安装版 `.9` 的隐藏 Electron 窗口采集现状：会话工具栏、新手操作指引、新建工作区弹窗。原入口只打开创建表单；并行说明集中解释分屏和工作树，没有对比产出入口或材料准备动作。

此次沿用当前工具栏、Popover、任务创建和聊天文件引用链路；新增引导与两个任务模板，创建弹窗使用对应任务标题和下一步说明。没有另建任务执行器或自动排名页面，也未把审阅历史版本比较混同为多个任务的产出比较。
