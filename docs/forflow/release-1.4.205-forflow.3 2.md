# Forflow One 入门清单修复与数据传输测试版

版本 `1.4.205-forflow.3`，macOS arm64，2026-09-19。本版修复 `.2` 对入门清单的错误替换，并增加应用内权限和数据传输确认。安装与最终验收以交付目录 `release.json` 为准。

## 恢复原有引导

`.2` 把原 8 项交互清单替换为 6 段私有化说明，丢失了进度和操作入口；这是实现错误。现在恢复通知、默认智能体、CLI 与技能、集成服务、配置脚本、多个项目、并行工作树和浏览器共 8 项。保留完成条件和用户已有进度，私有化说明附在清单下方。设置中的清单入口始终可见，检测未完成时显示提示。

用户指出的两句英文已改为“并行开始另一项任务”“每个工作树都有独立分支，让并行任务的改动分别保存。”。18 个引导步骤及动作接入翻译目录，生成的终端标签和工作区状态也随语言切换；用户自定义名称、代码和第三方终端输出保持原意。

恢复“安装 CLI 和技能”操作后，私有版改用安装包内置技能进行本地安装，不再执行上游在线下载命令。安装仍经过原有技能包校验和冲突处理，用户修改过的同名技能不会被覆盖；远程或 WSL 环境明确提示需要在目标主机部署。本版不把本机技能安装结果计为远程主机已完成。

## 权限与上传

- 应用提供的网页文件上传、SSH/远程运行环境导入及远程剪贴板图片传输增加一次性中文确认，显示文件路径和目标。等待确认期间取消、超时或关闭界面会拒绝继续；开始传输前重新核对目标，远程环境同时核对配对身份。
- 内置浏览器的网站剪贴板读取、通知、麦克风和摄像头使用按当前页面确认。刷新、导航或关闭页面后清除授权；操作系统权限仍需用户单独允许。未知权限及不能确定归属的请求默认拒绝。
- 电脑操作助手保留 Forflow 独立身份，后台只读检查辅助功能和截屏权限；测试未开启这些系统授权，也未读取剪贴板或调用摄像头。
- 自有身份服务继续负责账号、管理员/成员角色、会话撤销及身份审计。当前本机服务地址仍为 `http://127.0.0.1:43120`，服务程序与本轮测试的源码一致，账号密码未进入报告或制品。

这里的确认覆盖应用提供的上述入口，不是终端或第三方 Agent 的网络沙箱；Agent 自行调用其他程序仍需客户的进程隔离、系统出站策略和数据授权。上传确认目前也没有接入独立审计存储。业务 RBAC、完整数据证据链、SSO 和客户现场合规验收仍是后续工作。

## 验证

- 65 个文件的 702 项单元/集成回归，包含审批生命周期、上传取消、目标变化、流式文件处理、技能冲突及中文引导。
- 11 项真实身份服务接口测试。
- 正式安装包与安装后的应用各通过 6 条 smoke/端到端场景：中文冷启动，Git 工作树/中文终端/文件编辑/差异/重启，自有账号，8 项交互清单与离线技能，网页权限与实际上传，用户指出的并行任务浮层。
- 清单测试从未完成状态开始，添加两个真实 Git 项目后验证对应条目完成，重载后状态保留；没有预置全部完成来代替验收。
- 上传测试使用合成数据和本机接收端：取消后接收 0 字节，允许后接收 32,795 字节，与源文件逐字节一致；页面刷新后网站权限重新询问。
- 三端生产类型检查、Forflow 安装包测试类型检查、改动代码质量检查、中文目录与运行时目录检查通过。中文目录共 14,455 项，保留 509 项登记的技术原文；实际界面另外通过渲染与截图检查。

上游全量 `typecheck:e2e` 是仓库明确标记为尚未启用的检查，本次尝试仍报告旧测试类型错误和未安装的云端包；保留原始失败日志，未将其写成通过，也未修改其检查范围。本次新增了单独的 Forflow 安装包测试类型检查，修正本套件的问题并通过。没有执行上游全量 E2E 或真实 SSH 主机传输，SSH 和运行环境目标变化目前由针对性测试验证。

所有测试使用隐藏窗口和隔离 HOME/用户数据。桌面采用本机 ad-hoc 签名，未做 Developer ID 公证；其他 OS/CPU、中文输入法候选窗、国内模型和第三方 CLI 的真实认证/任务仍未验收。模型凭据按用户安排继续等待配置。

## 安装与回退

应用已更新到 `/Applications/Forflow One.app`。打开“设置 → 入门清单”即可查看恢复的 8 项；部署说明在其下方。本轮安装不修改用户项目、账号服务数据或原 Orca 应用。

`.2` 回退副本保留在 `~/Library/Caches/Forflow One/rollback/1.4.205-forflow.2-before-forflow.3/Forflow One.app`。需要回退时先退出 Forflow，再恢复应用文件；账号服务和用户数据单独保留。交付目录含 ZIP、SHA-256、源文件指纹、签名与解压复核、测试 JSON 和实际截图。
