# 手机端首次使用引导 · 2026-10-08

在手机 PR #4 的 `codex/forflow-mobile-direct` 分支继续改进，基于 `af6425d6461564de1410e204de4606d21c3e1aca`。保留深色设计、独立设备授权与本地网络配对。

## 使用变化

- 首屏围绕“在手机上继续工作”说明用途和网络前提，配对后指向工作区与智能体。
- 会话选择页解释自然语言聊天与命令终端的用途，明确推荐聊天。新设备无已存偏好时优先聊天；已有默认视图和单独标签偏好保留。无法读取或识别偏好时仍回退终端，聊天能力与 SSH 可读性继续按原机制判断。
- 工作区列表补充下一步说明；空工作区、空会话和查找智能体的状态使用中文，引导选择智能体或工具。
- 新建菜单分成“智能体对话”和“工具”，命令终端、浏览器和笔记各自命名。长按切换、聊天输入和停止等提示统一为中文。
- 空聊天提供两个任务示例。点击只填入草稿，由用户修改并发送；已有草稿、图片、消息、正在工作或连接不可用时不显示示例。
- 申请相机权限的动作改为“允许相机并扫码”，返回按钮扩大为 44 点并补充可访问名称。配对超时提供保持电脑运行、检查局域网或 VPN、重新生成配对码的具体步骤。
- 修复未授权相机时粘贴配对码仍停留在权限页的问题：现在可显示连接进度、无效配对码和重试，不强制申请相机权限。

本轮复用既有配对、工作区、智能体创建和消息发送路径，未增加 RPC 字段、流操作码或远程状态来源。Git 工作区与普通文件夹工作区沿用同一引导。
