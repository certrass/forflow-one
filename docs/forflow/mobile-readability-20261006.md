# 手机端首页与可读性 · 2026-10-06

在手机 PR #4 的独立分支 `codex/forflow-mobile-direct` 上继续改进，沿用现有深色设计与设备直连授权。

## 页面改动

- 首页先显示「继续上次工作」，再显示配对 / 新建和电脑列表。累计活动移至下方，模型账号用量仍使用原有数据来源。
- 继续卡保留工作区名称与项目 / 分支信息，明确区分「继续工作」与「连接电脑后继续」。离线时不再降低整张卡片透明度，操作仍禁用。
- 电脑连接提示、工作区数量与历史记录改为中文。仅改显示函数，连接判定、重试阈值、缓存过期规则不变；失联不表示任务已经结束。
- 任务来源按钮增加文字，脱离整张卡片的嵌套按钮；设置、电脑菜单和任务来源控件至少 44 点，操作行允许换行。
- 设置分为「使用偏好」「连接与支持」；账号与隐私按设备授权、数据与加密、连接方式分段。
- 首次连接页允许滚动，步骤说明使用现有正文 token；长连接恢复说明不再限定两行。
