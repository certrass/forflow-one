## 本版体验

- 会话工具栏新增「操作指引」：按需展开 Codex 对话、文件引用、分屏与并行、结果检查、浏览器设计反馈五个主题。可关闭、重开，也可重新显示指向分屏与并行控件的浮层。
- 新建任务增加三种可编辑示例：理解项目、实现小改动、检查已有改动。已有说明／导入资料不会被示例覆盖；创建期间禁止修改输入。示例只准备草稿，不自动发送。
- 分屏和项目创建浮层明确 Git 工作树与普通文件夹的区别，避免把共用文件的窗格当作独立任务环境。
- 任务页补充术语和直接创建入口说明；飞书筛选、读取及导入按钮接入已有引导定位。
- 快速上手围绕首个任务重排，优先讲项目、Codex、任务说明、参考资料和结果检查；账号、模型与升级说明保留为可展开内容。原八项入门及完成检测规则保留。

完整步骤见 [新手指引](newcomer-guidance.md) 和 [操作手册](user-manual.md)。包含 `.16` 飞书任务功能，不必先安装中间版本。
