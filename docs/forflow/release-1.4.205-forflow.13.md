# Forflow One 1.4.205-forflow.13 本机测试版

2026-09-20，macOS arm64，国内私有默认配置。当前状态：安装包已通过验证，等待正在运行的 `.11` 正常退出后安装。

本版把中间智能体窗格的 GUI 入口显式展示：常驻“对话／终端”“分屏”“并行任务”“文件与成果”。复用现有终端控制器、会话转录和 Native Chat Portal，切换不重新创建进程或工作区。原快捷键、右键、文件预览、浏览器元素选取和设计意见发送保留。

新配置默认启用受支持智能体的桥接对话，暂不默认启用结构化执行；旧配置可点击“对话”就地启用，已有默认视图和标签不批量迁移。设置写入失败或异步期间目标变化时不会误切其他窗格。结构化会话不显示虚假的终端入口；不支持的智能体／主机和普通 Shell 显示原因。
