## 下一批最具体的修改

1. GUI 首期集中于 Codex：按用户 2026-09-20 最新指示，国内 CLI 新适配与联调暂缓，既有入口与账户保留。优先验证 Codex 同会话输入、执行反馈、停止、材料引用和审阅，见 [GUI 工作台](gui-workbench.md)。此前 CodeBuddy、Qoder CN、TRAE CN 等计划保留在 [国内 CLI 接入](domestic-cli.md)，不再作为当前并行开发项；真实国内 API 凭据继续由用户稍后配置。
2. 执行器管理：企业 profile 绑定 allowed agents、binary digest、provider、model、endpoint、credential ref；启动时继承经过裁剪的环境。界面未勾选不能替代服务端限制；Agent 子进程的任意网络访问最终由 worker 网络策略控制。
3. 安装包：从 `electron-builder.config.cjs` 拆可共享构建核心与各产品身份。Forflow 目标包名 `forflow-one`、appId `cn.forflow.one`。先完成本机 macOS 并存包，再在真实 Windows/Linux runner 上完成对应 hooks/native 构建。
4. 首个治理样例：代码仓库内“研发变更审查”任务，固定输入 commit、规则版本、测试报告、diff 和人工结论。它与研发用户匹配，也能独立检查真实文件和权限；之后再扩展到数据库业务调查。
5. Q2Q：以当前 `/Users/zezhou/Desktop/forflow-q2q` 的项目评审生命周期和 Claim 内核为接口源，固定版本后通过本地服务调用。不把全部历史评分脚本复制进 Electron，不把 Investment/Production/Value Gate 与 PROJECT_REVIEW 混名。

| 环境变量             | 新入口公开 `FORFLOW_*`；兼容层映射内部 `ORCA_*`          | 新旧同时出现时有明确优先级/冲突错误；不静默把旧 token 带入新部署                   |

| 内部目录/类名        | 逐模块按维护价值迁移                                 | 不把“去掉所有 Orca 字符串”当质量指标，否则会破坏扩展与上游补丁合并                 |

## W4 必须验证的负向用例

| 用例                                | 期望行为和证据                                                           |
| ----------------------------------- | ------------------------------------------------------------------------ |
| A 项目用户读取 B 项目文件／数据行   | 执行前拒绝；产生 policy decision ID；结果及缓存均不返回越权数据          |
| 取数后撤权，运行还未结束            | 停止后续读取/导出，失效缓存授权；记录撤权版本与已执行范围                |
| 输入文档诱导上传源文件              | 文档不授予权限；工具/网络策略拒绝未授权出口；记录拒绝和来源              |
| 审批后产物变化                      | 旧批准不适用新 hash；需要对新版本作相应决定                              |
| 相同 request ID 重试但参数变更      | 拒绝幂等冲突；原 receipt 保持；不重复写外部系统                          |
| 客户端断线、worker仍执行            | 状态变为无法确认；向执行主机查询或恢复，不重复派发非幂等动作             |
| 审计存储不可用                      | 对受控写入按任务风险策略停止或进入有界队列；不得无记录继续执行高影响操作 |
| 使用未批准模型／插件、URL跳转到新域 | 启动或出站层拒绝；不会自动回退到上游公网服务                             |
| 模型说“测试通过”，实际退出码失败    | 实际测试 receipt 优先；Claim 保留冲突，禁止生成虚假的通过状态            |
| 删除/导出/恢复证据                  | 有版本、权限、保留与操作事件；缺口可解释，恢复后引用可验证               |

以上为待实现验收合同，不是本轮已经通过的测试清单。
